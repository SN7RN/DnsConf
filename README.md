# Скачать GAZ Dub

[Скачать один архив доставки (~400 МиБ)](https://github.com/SN7RN/DnsConf/archive/refs/heads/gaz-dub-distribution.zip)

[Скачать отдельно шесть голосовых примеров (~1 МиБ)](https://raw.githubusercontent.com/SN7RN/DnsConf/gaz-dub-distribution/GAZ-Dub-GTA-VI-Voices-2026-11-14.zip)

1. Распакуйте архив доставки целиком (нужно около 2 ГБ свободного места для распаковки и восстановления; модели требуют дополнительного места).
2. Откройте RESTORE-GAZ.cmd. Он проверит все восемь частей по SHA-256 и восстановит исходный GAZ-Dub-Windows11-2026-11-14.zip. Python, интернет и права администратора для восстановления не нужны; используется штатный PowerShell без изменения политики выполнения.
3. Распакуйте восстановленный ZIP и откройте GAZ-Start.cmd. Внутри есть НАЧАТЬ.md.

Основной ZIP не пересобирался: 418771730 байт, SHA-256 `14b30eb004b702066a0dfc828d2d9de477756f6418145db8af8da58fdf5e989c`. Разбиение потребовалось из-за ограничений GitHub на размер одного файла и недоступности загрузки Release assets через используемое подключение.

Голоса ZIP: 1024128 байт; SHA-256 `09d7de9e9a1f387681d42a61715f5e690b5575b4143afcf8c1b92d0307ccf4cc`.

Это отдельная ветка доставки. Основная ветка DnsConf и её настройки не изменены. В основном ZIP сохранены исходники GAZ Dub, коммит c0b199ad9964c073772cbe1a7e262ae061c190d0, лицензии и зависимости. Исходный проект: https://github.com/pigro141/livedub (GPL-3.0-or-later).

Windows Portable собран в Linux; запуск на Windows/RTX 5080 не проверен. Сходство голосовых кандидатов с актёрами GTA VI не подтверждено. Эта публикация решает доставку уже существующих файлов, не подтверждает новые функции.
