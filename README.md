# GAZ Dub — доставка Windows-пакета

Эта отдельная ветка используется только для доставки уже собранного GAZ Dub. Основная ветка DnsConf не изменялась.

Скачать Windows-пакет и шесть образцов голосов: https://github.com/SN7RN/DnsConf/releases/tag/gaz-dub-2026-11-14

В основном ZIP находятся исходники LiveDub с доработками GAZ Dub (коммит c0b199ad9964c073772cbe1a7e262ae061c190d0), лицензии, Windows runtime, автоустановка и НАЧАТЬ.md. Исходный проект: https://github.com/pigro141/livedub — GPL-3.0-or-later.

Portable собран в Linux. Запуск на Windows/RTX 5080 не проверен. Публикация является доставкой существующего результата, а не подтверждением Windows-интеграции.
